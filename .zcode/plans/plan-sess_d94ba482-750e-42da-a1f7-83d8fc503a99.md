# 公式渲染支持:KaTeX 纯 Rust 服务端渲染 + 样式全内联

## 方案选型(已验证)

本项目输出目标是公众号 HTML(剥 class/id/style/script,见 render.rs 约束),mermaid 已确立「服务端渲染、单文件自包含」路线,公式沿用。选择 **`katex` crate(v0.4.6,默认 quick-js 特性,xu-cheng/katex-rs,mdbook-katex 同款)**:内嵌 KaTeX JS 跑在 QuickJS 里,纯 Rust 编译、离线、无浏览器无子进程,在管线内直接出 HTML。

已验证可行性(unpkg katex.min.css):常用构造(分式/上下标/根号/vlist)**无伪元素依赖**;伪元素仅版本号、拉伸箭头、公式编号等可降级场景;子代/后代选择器约 20 条可枚举。故把 KaTeX 的 class 布局 CSS **内联化进 style 属性、删掉 class** 即满足公众号白名单。

排除的替代方案:在线公式转图片服务(codecogs 等)不支持 `\text{中文}`——用户示例恰有 `\text{ 股}`;本地图片引擎需 node+puppeteer 栈,过重。

## 实现步骤

1. **依赖**:`Cargo.toml` 加 `katex = "0.4"`(首次构建会编译内嵌 QuickJS C 源,变慢一次;二进制约 +2MB)。

2. **新模块 `src/math.rs`**:
   - `normalize_display_math(md)`:把**行首** `$$...$$`(单行或多行、含空行)改写为 ` ```math ` 围栏,公式原文走 Code 节点,天然避开 markdown 转义(`\\`→`\`)与 `Q_{net}` 类下划线解析干扰;扫描时跳过 ```/~~~ 围栏内部、保留缩进;列表/引用内的 `$$` 不改写(留给行内兜底)。
   - `split_inline_math(text) -> Vec<Segment>`:Text 节点行内 `$...$`/`$$...$$` 切分,规则仿 remark-math:开 `$` 后不能是空白,闭 `$` 前不能是空白、后不能紧跟数字(防 "价格 $5 和 $3" 货币误判),`\$` 转义跳过。
   - `render_math(latex, display) -> Option<String>`:katex crate(`OutputType::Html`、throw_on_error)→ 内置精简样式表 + 带父子上下文的小遍历器,把 class 规则(vlist 系/frac-line/sqrt-sign/delimsizing/op-symbol/mspace/lap 系等)合并进 style 属性、删 class;字体映射系统衬线栈(Times/Georgia/系统 CJK);未知 class 自然 no-op 安全降级;KaTeX 报错返回 None。
   - 配套单测。

3. **管线接线**:
   - `lib.rs`:`pub mod math`;`RenderOptions` 加 `pub math: bool` 并手写 Default(`math: true`——现有调用点全走 `..Default::default()`,不受影响);render_markdown 在 parse 前对 body 做 normalize(lib.rs:55-75)。
   - `transform.rs` finish 第 6 步(transform.rs:163-177 后):Code lang=="math" → `Block::MathBlock { latex, original }`(仿 MermaidBlock)。
   - `render.rs`:`Ctx` 加 `math: bool`(render.rs:14-27);`render_block` 加 MathBlock 分支 → 居中 section(margin 16px 0 / text-align center / overflow-x auto)包 KaTeX display HTML,失败兜底回主题色代码卡(用 original);`inline_node` 的 Text 分支(render.rs:518)→ split 后 Math 段渲染行内公式、Literal 段照旧。`--math off` 时全部保持字面输出。

4. **CLI**(`main.rs`,仿 --mermaid 模式 main.rs:54-56/294-299):convert 加 `--math auto|off`(default auto)+ `validate_math` + convert_one(main.rs:183 附近)传 `math: cli.math != "off"`。UI/publish 不加 flag(纯服务端渲染,编辑器预览/发布自动生效),默认开启。

5. **测试**:
   - math.rs 单测:normalize(单行/多行/围栏内不动/缩进)、split(货币、`\$`、`$$`)、render 产物无 `class=`/`id=`/`<style`、`\text{ 股}` 字符保留。
   - transform.rs 单测:```math 围栏 → MathBlock(仿 transform.rs:290 mermaid 测试)。
   - `tests/fixtures/sample.md` 增加公式小节(直接用用户给的「3.2 净预估持仓」两个 $$ 公式 + 一个行内公式),`UPDATE_SNAPSHOTS=1 cargo test` 重建 6 主题快照;现有约束测试(render.rs:58 no class= 等)自动把关内联化质量。
   - cli.rs 加一条 `--math off` 冒烟(字面输出)。

6. **文档**:README 功能列表加「数学公式」章节(支持 `$...$`、`$$...$$`、```math;渲染方式;`--math off`;限制:公式字体走系统衬线栈、拉伸箭头/SVG 类构造在公众号可能退化),模块表加 math.rs,CLI 参数处加 --math。

7. **端到端验证**:`cargo test` 全绿;用用户的公式片段跑 `md2html --stdout` 人工检查 HTML(居中、无 class、股字完整)。

## 已知限制(写进 README)

- 公式字体依赖系统衬线字体,大型定界符/大算符形高可能略退化;
- `\overrightarrow`、`\overbrace` 等依赖 SVG/伪元素的构造降级显示;
- 行内 `$...$` 中的 `\\`(矩阵换行)会被 markdown 转义吃掉;块级 `$$`/```math 走围栏保留原文,不受影响。
